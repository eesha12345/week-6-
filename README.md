# Week 6 - Sentiment Analysis Classifier

## Objective
Build a Sentiment Analysis application using Machine Learning and Streamlit.

## Technologies
- Python
- Pandas
- Scikit-learn
- NLTK
- Streamlit
- Joblib

## Features
- Text preprocessing
- TF-IDF Vectorization
- Logistic Regression
- Positive/Negative prediction
- Interactive Streamlit interface

## Run

python src/train_model.py

python src/predict.py

streamlit run app.py
